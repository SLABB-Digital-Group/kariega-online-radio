# Kariega Online Radio — Clean Professional PWA

A clean, responsive, installable Progressive Web App for Kariega Online Radio.

### Includes
- Modern mobile + desktop responsive design
- Installable PWA with manifest and service worker
- Live Zeno.fm player
- Monday–Sunday programme schedule
- Dynamic On Air Today display
- Presenter directory
- Partners, About, Contact and Join pages
- Real Kariega heritage photography supplied by the project
- Correct heritage name: **Zola Nqini**
- GitHub Pages / cPanel-friendly static files
